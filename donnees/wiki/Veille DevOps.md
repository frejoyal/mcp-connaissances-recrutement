# Veille DevOps

Les domaines de recrutement les plus demandés incluent :
*   **Fournisseurs Cloud :** AWS, Azure et GCP. Azure est dominant dans les secteurs public et financier.
*   **Conteneurs et orchestration :** Docker, Kubernetes.
*   **Infrastructure en code :** Terraform, Ansible.
*   **Intégration et livraison continues :** GitHub Actions, GitLab CI.
*   **Observabilité :** Prometheus, Grafana.
*   **Ingénierie des données :** Python, SQL, Scala, Apache Airflow, dbt, Snowflake, BigQuery, Azure Synapse, Kafka.

Les certifications les plus courantes sont :
*   AWS Certified Solutions Architect (Associate ou Professional).
*   Microsoft Azure Administrator (AZ-104) et Azure Solutions Architect Expert (AZ-305).
*   Certified Kubernetes Administrator (CKA).
*   Databricks Certified Data Engineer Associate.
*   SnowPro Core.
*   Microsoft Fabric Data Engineer Associate (DP-700).

Une certification ne remplace pas l'expérience ; lors de l'entrevue, un exemple de déploiement mené par le candidat est toujours demandé. Pour les rôles de données, l'accent est mis sur la qualité des données, les tests, et la gestion des données réglementées, surtout dans les secteurs de l'assurance et de la finance.

Signaux d'alerte à surveiller :
*   Un candidat listant dix outils sans pouvoir décrire un incident qu'il a réglé.
*   Une expérience uniquement en laboratoire pour un poste nécessitant de la production.
